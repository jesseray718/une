# UNE

**Joule-native computational substrate for the OpenRoot lattice.**

## What this is

UNE (and its surrounding computational_flow) is the software and measurement layer that treats useful work, energy, and coordination cost as first-class quantities. It contains:

- Agape engines and cooperation mathematics
- Thermodynamic ledgers and η (useful joules / human joules) tracking
- Seed extraction, context bridges, and postulate systems
- Tools for offline-first, phone-native, and low-power operation

## Role in the Lattice

UNE is the nervous system.  
OpenRoot defines the physical and systemic goals; UNE provides the measurement, verification, and coordination logic that makes those goals observable and improvable.

## Bigger Picture

The larger project aims to build infrastructure that increases real useful capacity for the lowest-capability participants while making pure cooperation the lowest-cost strategy. UNE exists to make that claim measurable instead of purely aspirational.

## Current Status

Active development. Core engines, seed systems, context bridges, and ledgers are present and in use.

## Key Entry Points

- `computational_flow/` — main engines (agape_*, extract_seed, ledgers)

- `seeds/` — extracted high-value statements
